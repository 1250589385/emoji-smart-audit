# 表情包智能审核 (Emoji Smart Audit)

麦麦（MaiBot）插件：**发送前真正"看"懂表情包，再判断配不配这句话**。

## 解决什么问题

麦麦默认的表情包选择靠「文字标签 + 低阈值语义匹配」，比如标签写着
`可爱,羞涩,无奈,萌,疲惫`，只要聊天语义沾边 0.3 就会发。问题：

- 群里有人在难过，它发个无语/搞笑表情
- 标签写得不准，图的内容和标签对不上
- 完全不看语境，气氛严肃时也发

**本插件的区别：把表情图真的发给视觉模型看，再结合最近聊天语境判断。**

## 工作流程

```
麦麦要发表情
   ↓
① 看图：表情图交给视觉模型，得出真实含义
   ↓   例：「呆滞、无奈、无语、懵圈」
② 看语境：拉最近 N 条聊天记录
   ↓
③ 综合判断：这个表情配这句话、在这个气氛下合不合适
   ↓
不合适 → 撤掉表情，只发文字（不会发空消息）
合适   → 原样放行
```

## 实际效果

| 场景 | 判断 | 理由 |
|---|---|---|
| 群里有人被骂难过，麦麦说「别难过」+ 无语表情 | ❌ 拦下 | "偏丧和调侃，与安慰对方的语境不匹配" |
| 大家在吐槽 996，麦麦说「社畜的命啊」+ 无语表情 | ✅ 通过 | "与加班疲惫的无奈很契合" |

## 安装

把整个文件夹放到 MaiBot 插件目录：

```
%APPDATA%\MaiBotOneKeyDesktop\<实例哈希>\modules\MaiBot\plugins\local_emoji-smart-audit\
```

重启 MaiBot，或在 WebUI 重载插件即可。

## 配置说明

全部配置都能在 WebUI 里改，不用手动编辑文件。

### 通用设置

| 配置项 | 默认 | 说明 |
|---|---|---|
| 启用插件 | 开 | 总开关 |
| 配置版本 | 1.0.0 | 请勿手动修改 |

### 审核行为

| 配置项 | 默认 | 说明 |
|---|---|---|
| 启用审核 | 开 | 关闭后表情包不再审核 |
| 看图模型 | `QoderCN-QF` | 需要支持视觉的模型。留空则只靠文字标签判断，准确度下降 |
| 判断模型 | `fast_model` | 建议用便宜快速的任务名，也可填 `planner`、`replyer` |
| 严格程度 | `normal` | `loose` 只在明显冲突时拦 / `normal` 默认 / `strict` 稍不搭就拦 |
| 参考消息条数 | 12 | 审核时看最近多少条聊天，建议 8~20 |
| 审核超时（秒） | 12 | 超时按「超时处理方式」执行 |
| 超时处理方式 | `keep` | `keep` 保留表情正常发 / `drop` 撤掉表情 |
| 审核概率 | 1.0 | 1.0=每条都审，0.5=一半概率审 |
| 跳过审核的字数门槛 | 2 | 文字太短没有语境，直接放行 |
| 记录审核日志 | 开 | 日志里能看到通过/拦下及理由 |

## 设计原则

- **零成本**：走本地 OFM 网关的免费渠道模型，不调用付费 API
- **绝不影响说话**：任何异常、超时都默认放行，审核失败不会导致消息发不出去
- **可回退**：把「启用审核」关掉就完全恢复原样，不改主程序

## 依赖

- MaiBot 1.0.0 ~ 1.3.99
- 插件 SDK 2.4.0+
- 一个支持视觉的模型（用于看图，可选但强烈建议）

## 已知限制

- 看图会多一次模型调用（约 4 秒），不过已包在审核总超时里
- 多张表情时只仔细看第一张，其余按"类似"处理以省 token
- 纯表情消息（没有文字）不审核，因为没有参照物判断不准
